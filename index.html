Problem and scope

Problem statement and objectives

Heart disease prediction papers often apply a standard GA or PSO to a classifier and report accuracy alone. That setup is common, so it adds little new knowledge. This project changes the optimizer and reports more than accuracy.

  1. Design a modified hybrid evolutionary optimizer that combines GA and PSO operators.
  2. Use it to select features and tune hyperparameters of the classifier on Cleveland and Statlog.
  3. Compare against plain GA, plain PSO and a baseline classifier, using more than accuracy.
  4. Add a SHAP explanation layer that outputs plain-language reasons for each prediction.
Sustainable Development Goal

SDG 3, Good Health and Well-being. Earlier and more transparent screening for cardiovascular disease supports target 3.4 on reducing premature deaths from non-communicable diseases.

Methodology

Pipeline

Data moves through five stages. The highlighted stage is where the novelty sits.

1 · Data

Cleveland and Statlog. Merge or evaluate separately, handle missing values, encode categorical features, scale numeric ones, then split for cross-validation.

2 · Optimizer

Modified hybrid GA-PSO. Particles move by PSO velocity updates. The weakest part of the population is replaced each generation using GA crossover and mutation. The modification to this loop is the core contribution.

3 · Classifier

Machine learning model. The optimizer searches over the feature subset and the classifier hyperparameters. Fitness is validation performance, not training accuracy.

4 · Evaluation

Beyond accuracy. Precision, recall, F1, AUROC, number of selected features and run-to-run variance across repeated seeds.

5 · Explanation

SHAP layer. Feature contributions are converted into a short plain-language statement for each patient record.
